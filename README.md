# Staff Portal Sample

**Staff Portal Sample** is an original, self-contained Laravel 11 demonstration project built to
showcase clean architecture patterns: thin controllers, single-purpose Actions, Policy-based
authorization, Form Request validation, and event-driven activity logging. It implements a small
internal portal with passwordless OTP login, role-based access control, a department-scoped
document library, and a queued activity log.

> **Note**: This is a wholly original portfolio sample. It shares no code, logic, configuration,
> or naming with any client project. All names, identifiers, and data are invented.
